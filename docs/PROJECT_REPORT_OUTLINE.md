# Project Report Outline

## 1. Title
Smart Campus Navigation System Using Graph Algorithms

## 2. Abstract
This project models campus locations as vertices and paths as weighted edges. It demonstrates Dijkstra's Algorithm for minimum-distance routing, BFS for fewest-edge routing, and Prim's Algorithm for a Minimum Spanning Tree. A Java Swing interface lets the user select locations and view algorithm results.

## 3. Problem Statement
Students and visitors may need a simple way to understand routes between campus buildings. The project demonstrates graph-based route planning using sample data.

## 4. Objectives
- Represent campus paths as a weighted graph.
- Find shortest weighted routes with Dijkstra.
- Demonstrate BFS traversal and fewest-edge routing.
- Construct an MST with Prim.
- Visualise algorithm results and discuss complexity.
